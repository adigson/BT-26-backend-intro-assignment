# Backend Introduction Assignment

A small Node.js command-line application created for the BeTechified backend development track.

## Features

- Prompts for a user's name, age, and favorite programming language.
- Validates each response and asks again when input is invalid.
- Formats and displays the completed profile.

## Requirements

- Node.js 18 or newer

## Run the application

From the project directory, run:

```powershell
npm start
```

Alternatively:

```powershell
node intro.js
```

Enter a response at each prompt. Age must be a whole number between 1 and 120.

## Run tests

```powershell
npm test
```
